#Backend - Inventario de Productos

API REST desarrollada con Django REST framework para gestionar un catalogo de productos (crear, consultar, actualizar y eliminar)

##Instalacion
1. Crear entorno virtual:python -m venv env
2. Activar entorno virtual 
3. Instalar dependencias:pip install -r requeriments.txt
4. Ejecutar migraciones:python manage.py migrate
5. Levantar el srevidor:python manage.py runserver
